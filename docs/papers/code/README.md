# Code of the Indexed Papers

Shallow clones of the public code behind the papers in [`papers.json`](../papers.json), plus a few small pipeline components, for private reading. The `code` field of each paper in `papers.json` links its official repositories to the clones here (URL, licence, commit, local folder); `python docs/papers/check_papers.py` checks that each linked clone exists and is at the recorded commit.

## Rules

- **Read only.** The cloned code is untrusted. Never install, import, build or run anything from these folders: no `pip install`, no scripts, no notebooks, no Python with a clone on `sys.path` or as the working directory. Read the files as text.
- **Private and gitignored.** Only this README is tracked. The clones are not republished.
- **Licences vary.** "none" means the repository has no licence file, which grants no reuse rights. GPL, non-commercial and academic-only code is for reading only. Reimplement methods from the paper and own understanding; copy code only from permissively licensed repositories, with attribution.
- **No weights.** No working tree contains model weights. Weights linked from READMEs (Google Drive, SharePoint, Hugging Face) were not downloaded; most are trained on non-commercial data.

## How the Clones Were Made

Each repository was cloned as `docs/papers/code/<owner>__<repo>` at the head of its default branch on 7 October 2026 (Git Bash):

```bash
GIT_LFS_SKIP_SMUDGE=1 GIT_TERMINAL_PROMPT=0 git clone --depth 1 --no-checkout --filter=blob:limit=5m \
  --no-recurse-submodules -c credential.helper= -c core.autocrlf=false -c core.longpaths=true -c core.symlinks=false \
  https://github.com/<owner>/<repo>.git docs/papers/code/<owner>__<repo>
# then a non-cone sparse checkout that excludes the paths below, and
GIT_NO_LAZY_FETCH=1 git -C docs/papers/code/<owner>__<repo> checkout <default-branch>
```

- **Not downloaded:** files over 5 MB (weights, datasets, media). Git LFS objects and submodules were not fetched.
- **Excluded from the working trees:** compiled binaries (`.so`, `.o`, `.pyc`, `.wasm`), weight formats (`.pth`, `.pt`, `.ckpt`, `.h5`, `.onnx`, `.safetensors` and similar), paths invalid on Windows, and agent instruction files (`CLAUDE.md`, `AGENTS.md`, `.claude/`, `copilot-instructions.md`), which coding assistants would otherwise read as instructions.
- **PaddleOCR** is a large monorepo. Only `ppocr/`, `tools/`, the PP-OCRv5 and PP-OCRv6 detection and recognition configs and their algorithm docs are checked out.
- **Updating:** delete the folder, clone again with the commands above, and update `commit` in `papers.json`; `check_papers.py` warns when a clone's HEAD differs from the recorded commit.

Total size: about 1.2 GB on disk, including `.git`. Sizes below are disk use including `.git`.

## Not Cloned

- **Monorepo parts:** PaddleOCR beyond the sparse paths above (docs, deployment, PP-Structure, SDKs).
- **Submodules:** ArchCAD `modules/pointops`; DeepLSD `third_party/` (progressive-x, pytlbd, pytlsd, homography_est) and `line_refinement/pybind11`.
- **Unofficial ports and derivatives:** TF2DeepFloorplan and PyTorch-DeepFloorplan, FloorplanVLM reimplementations (no licence, non-commercial base model), ArchCAD-gpu, dwg-vision-object-recognition. The originals are here or unreleased.
- **Libraries used through pip:** ezdxf, pypdfium2, pdfplumber, PyMuPDF, IfcOpenShell, Shapely, networkx, timm; large frameworks and models (detectron2, MMSegmentation, Mask2Former, SAM 3, Qwen-VL, Docling). Not research code, or too large for reading.
- **Avoided:** Ultralytics (AGPL-3.0).
- **Not on Git:** Semap data and model, the room-connectivity code (Zenodo); Hugging Face weights.
- **Indexed papers without public code** (no link in the paper or found in [literature review §5.6](../../literature-review.md#56-licences-and-availability-as-found)): VectorGraphNET, Talebi-Kalaleh & Mei, Lv et al., Guo et al., TextCAD, PolarSym, FloorplanVLM (official), FELD, Lombardi et al., Peng et al. 2025 and 2026, Liang et al., Lin & Wang, Chang et al., BlueprintAgent, MuraNet, Chen et al. 2023, Dodge et al., GAT-CADNet (official), Sketch2BIM, Ayanzadeh & Oates, Khan et al., Ying et al.
